# Google Play Store Analysis - Task 2

## Objective
Perform category-wise analysis on Google Play Store data and create a choropleth visualization after applying the required conditions.

## Filters Applied
- Selected Top 5 Categories
- Excluded Categories:
  - A
  - C
  - G
  - S
- Highlighted apps with installs greater than 1 Million

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Plotly

## Files Included
- TASK-2.ipynb
- Task-2 Report.pdf
- README.md

## Steps Performed
1. Loaded the dataset
2. Cleaned missing and duplicate values
3. Converted installs column into numeric format
4. Identified top categories
5. Applied category filtering conditions
6. Created choropleth visualization using Plotly

## Challenges Faced
After applying all required filters and exclusions, very limited categories remained for visualization.

## Output
A choropleth map visualization representing app category analysis based on installs.
