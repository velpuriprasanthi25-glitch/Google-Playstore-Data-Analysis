##  Outputs – Google Play Store Analysis Project

##  Objective

This folder contains all final visualization outputs from Task 1 to Task 6 of the Google Play Store Analysis project. These charts represent key insights derived from data cleaning, filtering, and analysis.

---

##  Outputs Included

* **Task 1:** Top app categories based on installs and ratings (Bar Chart)
* **Task 2:** Category-wise distribution analysis (Choropleth / Visualization)
* **Task 3:** Free vs Paid apps comparison (Dual-Axis Chart)
* **Task 4:** Install trends over time (Time Series Chart)
* **Task 5:** Relationship between app size, rating, and installs (Bubble Chart)
* **Task 6:** Category-wise install trends over time (Stacked Area Chart)

---

##  Summary

All outputs visually represent important patterns in the Google Play Store dataset such as user engagement, category performance, pricing impact, and time-based trends. These visualizations help in making data-driven insights easily understandable.
