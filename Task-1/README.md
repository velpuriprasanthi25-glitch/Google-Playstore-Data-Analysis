# Google Play Store Analysis - Task 1

## Objective
Analyze Google Play Store data and identify the top app categories based on installs and ratings after applying the required filters.

## Filters Applied
- Rating >= 4.0
- Size >= 10 MB
- Last Updated in January

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib

## Files Included
- TASK-1.ipynb
- Task-1 Report.pdf
- README.md

## Steps Performed
1. Loaded the dataset
2. Cleaned missing and duplicate values
3. Converted installs and size columns
4. Applied required filters
5. Found top app categories
6. Visualized results using bar chart

## Output
A bar chart showing the top 10 app categories based on installs after filtering the dataset.
