# Google Play Store Analysis - Task 3

## Objective
Analyze installs and revenue patterns for free and paid apps using a dual-axis chart after applying the required filters.

## Filters Applied
- Installs >= 10,000
- Revenue >= $10,000
- Android Version > 4.0
- Size > 15 MB
- Content Rating = Everyone
- App Name Length <= 30 characters

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib

## Files Included
- TASK-3.ipynb
- Task-3 Report.pdf
- README.md

## Steps Performed
1. Loaded the dataset
2. Cleaned missing and duplicate values
3. Converted installs and revenue columns into numeric format
4. Applied all required filters
5. Selected top 3 app categories
6. Compared free vs paid apps
7. Created dual-axis visualization for installs and revenue

## Output
A dual-axis chart comparing:
- Average Installs
- Average Revenue

for Free and Paid apps in the top categories.
