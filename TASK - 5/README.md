

# Google Play Store Analysis - Task 5

## Objective

Analyze the relationship between app size, average rating, and installs using a bubble chart after applying the required filters.

---

## Filters Applied

Rating > 3.5
Reviews > 500
Installs > 50,000
App Categories = Games, Beauty, Business, Comics, Communication, Dating, Entertainment, Social, Events
App Name should NOT contain “S”

---

## Tools & Libraries Used

Python
Pandas
NumPy
Matplotlib

---

## Files Included

TASK-5.ipynb
Task-5 Report.pdf
README.md

---

## Steps Performed

Loaded the dataset
Cleaned missing and duplicate values
Converted size, rating, installs, and reviews into numeric format
Applied all required filters
Selected required app categories
Created bubble chart using Matplotlib
Mapped app size to X-axis, rating to Y-axis, installs to bubble size

---

## Output

A bubble chart showing:

App Size vs Average Rating
Bubble size representing Installs
Filtered app categories comparison
